# VarData — домашнее задание «Работа с переменными»

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/AngryAlexQA/VarData/blob/main/VarData_California_Housing_EDA.ipynb)

Разведочный анализ данных (EDA) для улучшения метрик RMSE и R² линейной регрессии на датасете California Housing (`sklearn.datasets.fetch_california_housing`). Целевая переменная — `MedHouseVal`.

**Автор:** Александра Бужор

## Содержимое репозитория

| Файл | Описание |
|---|---|
| [`VarData_California_Housing_EDA.ipynb`](VarData_California_Housing_EDA.ipynb) | ноутбук с решением; все ячейки выполнены, вывод виден без перезапуска |
| `requirements.txt` | зависимости для локального запуска |

## Этапы работы

1. Загрузка данных и описание признаков
2. Проверка пропусков и дубликатов (не обнаружены)
3. Разбиение на обучающую и тестовую выборки 80 / 20 (`random_state=42`)
4. Базовая линейная регрессия на всех признаках
5. Распределение целевой переменной: правая асимметрия и 965 цензурированных значений 5.00001
6. Корреляционная матрица с цветными категориями силы связи, отбор признаков
7. Анализ и удаление выбросов по правилу Тьюки (1.5·IQR и 3·IQR)
8. Математические преобразования: логарифмы, квадраты и произведение координат
9. Выводы и сравнение моделей
10. Дополнительная проверка всех моделей на исходной тестовой выборке

## Результаты

| Модель | RMSE test | R² test | Признаки, на которых проводилось обучение |
|---|---|---|---|
| М1. Все признаки | 0.7456 | 0.5758 | все 8 исходных признаков без изменений |
| М2. Отбор по корреляции | 0.7407 | 0.5814 | `MedInc`, `HouseAge`, `AveRooms`, `Latitude`, `Longitude` |
| М3. + без выбросов | 0.6089 | 0.5925 | те же 5 признаков; удалены выбросы `MedHouseVal`, `AveRooms` (1.5·IQR), `MedInc` (3·IQR) |
| М4. + преобразования | 0.5957 | 0.6100 | `MedInc`, `HouseAge`, log(`AveRooms`), `Latitude`, `Longitude`, `Latitude²`, `Longitude²`, `Latitude·Longitude` |
| М5. + log(AveOccup) | **0.5522** | **0.6649** | признаки М4 + log(`AveOccup`) с винсоризацией 1–99 % |

**Главные выводы:**
- RMSE на тестовой выборке снизился с 0.7456 до 0.5522 (на 26 %), R² вырос с 0.5758 до 0.6649.
- Наибольший вклад дали математические преобразования: полином 2-й степени от координат и логарифм `AveOccup`. Корреляция `AveOccup` с целевой на сырых данных была почти нулевой (−0.02) из-за выбросов, а после логарифмирования проявилась связь r ≈ −0.26.
- Проверка на исходной тестовой выборке показала: удаление выбросов само по себе модель не улучшает (снижение RMSE в основном связано с более «лёгким» тестом), а преобразования признаков дают реальный прирост качества.
- Линейная регрессия справляется с задачей лишь частично: треть дисперсии стоимости остаётся необъяснённой, а на дорогих и дешёвых районах видна систематическая ошибка.
